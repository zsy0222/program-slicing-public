# Experiment reports

`reports/` stores human-readable, release-ready experiment descriptions and summaries.

- `briefs/`: current progress briefs.
- `defects4j/`: controlled real-defect summaries and dynamic-slice reports.
- `workflow/`: experiment design and workflow documents.
- `scripts/`: self-authored report builders.

Raw data supporting a report remains local unless it has been normalized, reviewed, and cleared for release.
