# FC v3 任务与验收协议

日期：2026-10-08。最新状态：工具/开发验收及原42候选准入完成，17例基线配对与解释器匹配、其中5例完整FC准入；其120次小规模模型调用及评价现已完成，见[实际模型实验报告](../reviews/fc_small_model_experiment_2026-10-08.md)。此前准备执行见[验收报告第9节](../reviews/fc_native_acceptance_2026-10-08.md#9-fc-v3任务打通与原42候选验收5例完整准入)。下文仍为原冻结的方法与执行前状态定义，不以实际结果反向修改；原 v2、v3 分析器与历史负结果不修改。

## 1. 本轮范围

原源码筛选在810个未暴露题目/相似性簇各固定一个代表后得到42个语法支持候选，768个不支持；目标50尚未达到。先在10个已暴露且通过原生开发门槛的案例上验收新任务适配器，之后冻结实际提示、评估与工具哈希，再读取这42个候选的测试和参考程序。逐例保留拒绝原因，不补选，不根据确认结果修改分析器。

FC 指自动生成的“已定义、固定观察路径后缀反向条件”，不是原论文 Error Invariant、一般C程序最弱前置条件或新补丁的全输入规格。支持int32、长度1–256的一维固定数组及初始化标记、int全局变量、结构化循环/分支、纯算术/比较/短路/三元表达式、多处整数输出。原v3限制和求解义务不变。

## 2. 四组实际输入

| 条件 | 实际输入差异 |
| --- | --- |
| FC0 | 匿名完整错误源码＋同一repair失败输入、实际与期望输出 |
| FC1 | FC0＋静态依赖行标记 |
| FC2 | FC1＋源映射的反向条件AST |
| FC3 | FC1＋该AST确定性转换的受控中文，不同时提供AST |

所有组的源码、失败信息、整个文件编辑权限完全一致。源码注释只在公共副本中以等位置空白替换，保持行列位置；原文私有保存。参考源码、held-out测试、预测答案、实际切点变量值、求解器结果与数据集提交身份不进入模型输入。自动检查AST↔中文完全往返相等；按实际序列化请求大小拒绝整例，不能只截短某组。

静态标记是保守、流不敏感、整数组may-alias及控制/输入顺序依赖的过近似，不称动态或双向切片。FC1-FC0还包含工具定位信息；FC2-FC1与FC3-FC2为主要比较。

## 3. 独立理解任务

在固定首个repair失败输入上，仅改变第一个整数：依次+1、−1、0。保留其他输入整数，重新以空格/末尾换行编码。原输入、重复值、int32越界、解释器未定义/超界、输出超过512个整数，以及原生stdout/退出码不完全一致的题记录为排除；没有替代题。每例至少有1题、最多3题。

题目只给新stdin，要求预测**原始错误程序打印的完整整数序列**，单值也以数组作答。答案来自错误程序原生执行，并与v3解释器的完整stdout字节与退出码核对；题构造函数不读取参考程序或held-out数据。评分严格匹配整数类型、次序、重复和长度；布尔、浮点、单标量、缺失/额外题号或无效格式为0分。空白格式不属于此理解主指标；本指标不是内部状态等价、根因理解或解释正确性的证明。

每个缺陷/簇先按题平均，再按重复平均；开放解释与疑似行只留作定性材料，不由GPT或另一模型评分，不拿参考补丁行当定位真值。理解与修复为不同独立会话，理解回答不会交给修复任务。

## 4. 修复与全测试

统一原始行号替换JSON，可修改整个提供文件。候选必须通过同一v3语法闸门，禁止宏、额外函数、指针/外部访问、预处理旁路与行拼接；保留原静态scanf/printf函数、格式与顺序。允许修复算法、分支、循环、int变量和受支持数组；不强制保持错误运行路径。

在新目录编译候选，使用数据集原Makefile的冻结gcc编译/链接参数；执行全部repair和held-out测试，记录实际测试ID、数量、原始stdout/stderr、退出码、资源标记和比较结果。GNU sed/diff使用C locale，保留行边界，不能用整数袋/序列相等替代补丁测试。先核对原比较脚本和编译配方，不支持的变体拒绝，绝不改数据集脚本。测试充分不等于全输入语义正确。

每测试5秒、256 MiB地址空间、合计1 MiB输出；编译30秒，准入父进程1 GiB；客机可用内存至少2 GiB、磁盘至少15 GiB。触及保护则保存记录并停止，不清理数据或改VM。参考与错误程序用于新候选评估器的正/负验收；这些执行不是LLM修复次数，也不增加独立bug数。

## 5. 冻结、调用与交付

每例4组×2项独立任务×3次重复＝24项请求；42例全部准入时最多1008项。已有Codeflaws→DeepSeek累计2000次授权保留，自动重试和反馈均0；历史调用未对账、实际返回模型身份未核验前关闭执行。预算预留在网络前落盘、加互斥锁，禁止重复任务或重置历史用量。当前工具没有HTTP客户端，本轮新增模型调用0。

请求参数继承既有任务合同，仅为待核验配置，不据此断言当前服务端版本。开始API前必须对账所有Codeflaws历史调用并记录请求/实际返回模型与参数；如配置需变更，应另存执行清单，不覆盖本轮冻结记录。

准入结束后独立从原始输出、测试身份、源码哈希、形式条件重算与公共视图重建进行审查，保存完整本机归档。报告源码候选数、已核对数、官方配对通过数、完整形式/任务准入数和拒绝原因；不能把42个源码候选称为42个可复现bug，更不能称为50个模型样本。
