# 项目交付与科研过程资料

本目录整理了项目综合报告、项目发展历程与交流记录、结项报告书，以及原始的研究、文献和实验记录。项目从程序切片与依赖分析的探索逐步发展到大模型辅助程序理解与修复的对照研究。方案、工具、输入、模型回答、评价回执与异常处理记录按原有结构保存，便于追溯研究过程。

## 材料说明

- `01_项目综合报告.docx`：研究问题、方法与主要发现。
- `02_项目发展历程与交流记录.docx`：项目的发展时间线以及对应历史材料。
- `03_结项报告书.docx`：按现有证据修订，并去除个人联系方式、出生年月和指导教师等个人信息的公开版本；未经脱敏的原件保留在本地。
- `原始记录/`：展开保存的实验记录、研究历程与文献资料。早期文件反映当时的认识，不能直接替代后续核验结论。

原始资料中有较长的文件路径。Windows 用户克隆时可使用 `git -c core.longpaths=true clone https://github.com/zsy0222/program-slicing.git`；目录中的 Git 属性用于保持文件原始字节，不需要将资料重新打成压缩包。

## 结果范围

现存31片归档回执覆盖3,057个案例和24,456条任务记录；另有先行共同验收的100例。31片的记录计数不等于对全部归档载荷重新进行独立流式验收。实验涉及不同模型指纹，分段对比属于探索性观察；独立确认样本尚不能支持控制流程信息带来稳定显著增益的结论。项目保留历史方案、失败和恢复记录，以便核对结论的形成过程。
