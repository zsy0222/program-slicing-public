# Literature entry points

The authoritative literature database is maintained in [`../paper/`](../paper/):

- `paper/matrix/`: literature matrix and evidence map.
- `paper/notes/`: research questions, screening criteria, and reading notes.
- `paper/reports/`: literature audit and research summaries.

Original PDFs and early document lists are retained locally in `90_local_only/literature_sources/` and are excluded from release unless their license is explicitly verified. This directory deliberately does not redistribute papers.
