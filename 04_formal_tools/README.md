# External formal-analysis tools

This repository does not redistribute third-party source trees, JARs, benchmark binaries, or build products. Local copies are retained in `90_local_only/third_party_tools/` and ignored by Git.

Experiments have used external infrastructure such as Slicer4J, WALA, DG, and Giri where appropriate. Obtain each dependency from its official upstream repository and follow its license and installation instructions. Public experiment reports identify the tool role and version/commit when reproducibility requires it.
